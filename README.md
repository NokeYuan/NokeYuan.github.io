# nokeyuan.github.io

Personal academic homepage of **Baijiang (Noke) Yuan** — PhD candidate in AI in Healthcare at the University of Toronto and Machine Learning Associate at the Vector Institute.

Live at [https://nokeyuan.github.io](https://nokeyuan.github.io).

## Credits

- Built on the [academicpages](https://github.com/academicpages/academicpages.github.io) template, itself a fork of [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) by Michael Rose (MIT License — see `LICENSE`).
- Theme customizations (publication cards, dark mode, layout) adapted with thanks from [vinbhaskara.github.io](https://github.com/vinbhaskara/vinbhaskara.github.io).

## Local development

```bash
bundle install
bundle exec jekyll serve --config _config.yml,_config.dev.yml
```

The site is otherwise built and deployed automatically by GitHub Pages on push to `main`.
