# nokeyuan.github.io

Personal academic homepage of **Baijiang (Noke) Yuan** — PhD candidate in AI in Healthcare at the University of Toronto and Machine Learning Associate at the Vector Institute.

Live at [https://nokeyuan.github.io](https://nokeyuan.github.io).

Built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme (MIT License), layout inspired by [vahidbalazadeh.me](https://vahidbalazadeh.me/). Deployed automatically to the `gh-pages` branch by GitHub Actions on push to `main`.

## Local development

```bash
bundle install
bundle exec jekyll serve
```
